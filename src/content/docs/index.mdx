## Where Ironlark is

Ironlark is in closed pre-alpha. The host runs, maps load, mods run, and people play
on it. Large parts of the platform are not built yet: there is no dedicated server,
and you host by running the game. Mods are written in Rust with the `ironlark` SDK —
public and Apache-2.0, at
[github.com/ironlark-dev/ironlark-rust](https://github.com/ironlark-dev/ironlark-rust)
— and [your first mod](/modding/first-mod/) is a git dependency away.

These docs describe what exists today and say plainly where the edge is. Both lists
are public: [the boundary today](/boundary/), and [the roadmap](/roadmap/).

## What you can build

<CardGrid>
  <Card title="Maps" icon="pencil">
    Worlds authored in Blender as glTF, plus a small manifest. Host-owned data, not code.
  </Card>
  <Card title="Mods" icon="puzzle">
    WebAssembly components the host loads. They spawn things, react to touch and input, and talk to each other over a bus.
  </Card>
  <Card title="Gamemodes" icon="star">
    A mod that holds the gamemode role. It owns the rules a session plays by, including where players appear.
  </Card>
</CardGrid>
