The [interface reference](/reference/) says what every function does. These pages say
what to reach for and why, which the signatures cannot.

<Aside type="tip" title="If this is your first mod">
Read [Realms and the session lifecycle](/manual/realms-and-lifecycle/) first — everything
else assumes you know which realm your code runs in. Then read
[What you cannot build yet](/manual/not-yet/): it is short, and it will save you more time
than any other page here.
</Aside>
