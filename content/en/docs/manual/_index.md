The [interface reference](../reference/) says what every function does. These pages say
what to reach for and why, which the signatures cannot.

If you are writing your first mod, start with [Realms and the session
lifecycle](realms-and-lifecycle/) — everything else assumes you know which realm your code
runs in.

Before planning anything ambitious, read [What you cannot build yet](not-yet/). It is short,
and it will save you more time than any other page here.
